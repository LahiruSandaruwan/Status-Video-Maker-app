## 📝 Licensing Guidelines

### What You Need to Know:

1. **Always Check the License**
   - Read the specific license for each track
   - Some require attribution, some don't
   - Commercial use must be allowed

2. **Attribution**
   - If required, include in app credits section
   - Format: "Music by [Artist Name] from [Source]"
   - Can be in Settings > About > Music Credits

3. **Safe Licenses for Commercial Use**:
   - ✅ CC0 (Public Domain)
   - ✅ CC BY (Attribution required)
   - ✅ YouTube Audio Library (most tracks)
   - ✅ Pixabay License
   - ❌ CC BY-NC (Non-commercial only)
   - ❌ CC BY-ND (No derivatives)

4. **Best Practice**:
   - Download and keep license documentation
   - Create a Credits.txt file listing all tracks
   - Include attribution in app if required

## ⚙️ Technical Specifications

### Audio Format Requirements:
- **Format**: MP3
- **Bitrate**: 128-192 kbps (balance quality & file size)
- **Sample Rate**: 44.1 kHz
- **Duration**: 30-180 seconds (users can trim)
- **File Size**: Target < 3MB per track

### Processing:
If tracks need processing:
- Use Audacity (free) to trim, normalize, fade in/out
- Keep original files as backup
- Normalize audio to -3dB peak level

Add to Settings > About > Music Credits:
```

```
